## Confirmed classification defects to lock into regression fixtures

The following classes are known to be unsafe in the current production catalogue and must not survive SafetyEngine v2 as ACCEPT:

1. Occupied property.
2. Property sold unfinished / under construction.
3. "Obra nueva" combined with "en construcción".
4. Rustic plot / rustic dwelling.
5. Camping / bungalow product.
6. Bungalow on land presented as a house.
7. "Necesita mejoras".
8. "Semireformada".
9. Positive words embedded inside ambiguous/negative wording.
10. Condition not stated clearly.

## Gate for Step 6B

SafetyEngine v2 must classify the fixture corpus as follows:

- Explicitly unsafe or incompatible -> **REJECT**
- Potentially compatible but habitability/condition is not sufficiently established -> **REVIEW**
- Explicit ready-to-live wording with no contradiction -> **ACCEPT**

Negative evidence always wins over positive evidence.

## Non-negotiable invariants

- Never expose a property over **185,000 EUR**.
- Never expose fewer than **3 bedrooms**.
- Occupied / no-possession / rented / auction / proindiviso / non-mortgageable remains rejected.
- Safety changes must pass CI before any crawler job runs.
